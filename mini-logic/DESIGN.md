# mini-logic - 統合設計書

お絵かきロジック（ピクロス / Nonogram）パズルゲーム。

## プロジェクト方針
- **シンプル＆直感性**: 快適なドラッグ操作、スマホ・PC両対応の快適なUI。
- **多様なサイズ**: 5x5（初級）、10x10（中級）、15x15（上級）の豊富なステージ。
- **演出**: クリア時にドット絵カラーリングが完成するアニメーションとWeb Audio SE。

## ゲームルール
- **数字ヒント**:
  - 行・列の端に書かれた数字は、その行・列で連続して塗るマスの数を表します。
  - 数字が「2 3」の場合、2マス連続で塗った後、1マス以上の空きを挟んで3マス連続で塗ることを意味します。
- **操作モード**:
  - **塗りモード（⛏️）**: マスを塗ります（青色）。
  - **バツモード（❌）**: 塗らないマスに×印を付けます。
- **ドラッグ操作**:
  - マウスを押しながらなぞることで、一括で塗り/×印を入力可能。
  - 右クリック操作で瞬時に×印を切り替え。
- **ヒント一致検出**:
  - 正しくマスが埋まった行・列のヒント数字は半透明/ハイライト状態になり、進捗が直感的に分かります。
- **クリア条件**:
  - 正しいすべてのマスを塗りつぶすとステージクリア！完成したイラストが表示されます。

## 画面構成
1. **タイトル画面**: スタートボタン、遊び方説明モーダル。
2. **ステージ選択画面**: 5x5, 10x10, 15x15 のカテゴリ別ステージ選択。クリア済みのイラストとクリアタイムを表示。
3. **ゲーム画面**:
   - 行・列のヒント数値
   - 盤面グリッド
   - モード切替（塗り/バツ）、ヒント機能、リセットボタン
   - タイマー & ミスカウント
4. **リザルト画面**: 完成イラスト表示、クリアタイム、星評価（★3〜★1）、次のステージへ進むボタン。

## 技術スタック
- 言語: JavaScript (ES Modules)
- 基盤: オリジナル・シーン管理システム
- 描画: HTML DOM / CSS Grid / CSS Flexbox
- 効果音: Web Audio API (SoundManager)
