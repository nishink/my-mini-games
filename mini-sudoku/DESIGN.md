# mini-sudoku - 統合設計書

定番の9x9数独（ナンプレ / Sudoku）パズルゲーム。

## プロジェクト方針
- **シンプル＆直感性**: 数字選択キーパッド、メモ（仮置き）モード、直感的なタッチ・キーボード操作。
- **難易度別ステージ**: 初級 (Easy)、中級 (Normal)、上級 (Hard) のステージ。
- **アシスト機能**:
  - 同一番号・関連行/列/3x3ブロックのハイライト。
  - 重複数値のエラー検出表示。
  - メモ（ペンシル）モード。
  - ヒント・アンドゥ（1手戻す）機能。

## ゲームルール
- **盤面**: 9×9 グリッド（3×3の9つのブロック）。
- **ルール**:
  1. すべての行に 1〜9 の数字が1つずつ入る。
  2. すべての列に 1〜9 の数字が1つずつ入る。
  3. すべての3×3ブロックに 1〜9 の数字が1つずつ入る。
- **勝利条件**: すべてのマスを正しい数字で埋めること。

## 画面構成
1. **タイトル画面**: スタートボタン、遊び方・ルール説明モーダル。
2. **難易度選択画面**: 初級・中級・上級の難易度および問題選択。
3. **ゲーム画面**:
   - 9×9 ナンプレ盤面
   - テンキー（1〜9、消去、メモ切り替え、ヒント、アンドゥ）
   - タイマー & ミスカウント
4. **リザルト画面**: クリアタイム、星評価、次のパズルへの遷移ボタン。

## 技術スタック
- 言語: JavaScript (ES Modules)
- 基盤: オリジナル・シーン管理システム
- 描画: HTML DOM / CSS Grid
- 効果音: Web Audio API (SoundManager)
