# mini-shogi - 統合設計書

簡略化した5x5将棋（5五将棋）の最小構成プロトタイプ。

## プロジェクト方針
- **シンプル**: 5x5マス、初期配置6種類の駒（玉、飛、角、金、銀、歩）を使用。
- **AI対戦**: 簡易的な評価関数を用いたAIとの対戦機能。
- **持ち駒と成りの再現**: 本格的な将棋の基本ルール（取る、打つ、成る）をミニマルに実装。
- **DOM描画**: 盤面と駒はDOM/CSSで表現し、わかりやすい操作感を提供する。

## ゲームルール
- **盤面**: 5x5のグリッド。
- **初期配置**:
  - 先手（下側、5行目）：左から 飛(R)、角(B)、銀(S)、金(G)、玉(K)
  - 先手歩兵（4行目）：左端（5四）に 歩(P)
  - 後手（上側、1行目）：左から 玉(K)、金(G)、銀(S)、角(B)、飛(R)
  - 後手歩兵（2行目）：右端（1二）に 歩(P)
  - ※点対称の配置。
- **駒の動き**:
  - 玉 (K): 周囲8マスに1マス。
  - 飛 (R): 前後左右に何マスでも。成ると「竜 (竜王: +R)」になり、斜め4方にも1マス動ける。
  - 角 (B): 斜め4方向に何マスでも。成ると「馬 (竜馬: +B)」になり、上下左右にも1マス動ける。
  - 金 (G): 前後左右と斜め前に1マス。成らない。
  - 銀 (S): 斜め4方向と前に1マス。成ると「成銀 (+S)」になり、金と同じ動きになる。
  - 歩 (P): 前に1マス。成ると「と金 (+P)」になり、金と同じ動きになる。
- **成りのルール**:
  - 敵陣（先手なら1行目、後手なら5行目）に駒が進む、または敵陣内を移動するときに「成る」ことができる。
  - 歩が敵陣最奥に達したときは強制的に成る。
- **持ち駒（打つ）**:
  - 取った駒は自分の持ち駒になり、自分の手番に空いているマスに配置（打つ）できる。
  - 歩は最奥（1行目/5行目）には打てない。
  - 二歩（同じ縦列に自分の歩が2枚存在する状態）は禁止。
- **勝敗**:
  - 相手の「玉」を取るか、完全に詰ました方の勝利（簡易判定として「王手放置の禁止」および「王の捕獲」で勝敗を決する）。

## 遊び方 (How to Play)
1. **モード選択**: 「Player vs Player」または「Player vs AI」を選択。
2. **対局**:
    - 自分のターン：盤面の駒をクリックすると移動可能マスがハイライトされる。または持ち駒エリアの駒をクリックすると打てるマスがハイライトされる。
    - ハイライトされたマスをクリックして移動/打つを実行。
    - 成るかどうかの選択ダイアログ（可能な場合）。
3. **終局**: 玉が取られると終了。結果が表示される。

## 技術スタック
- 言語: JavaScript (ES Modules)
- 基盤: オリジナル・シーン管理システム
- 描画: DOM / CSS
